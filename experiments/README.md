# Experiment workspace

Save your research Python scripts here. The bench's Python tab opens this folder
and supplies the application modules on the script import path.

`loopback-message.txt` is the example 16-byte payload `WINLAB_TEST_0001`, without a
newline. Load it using **Transmit → TX files → Load message bytes**.

Generated `.wlab.json` captures and analysis files are ignored by Git. Share them
explicitly when needed; they do not need to be committed with the app source.
